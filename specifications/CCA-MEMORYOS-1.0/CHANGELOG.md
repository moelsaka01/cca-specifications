# MemoryOS Standard Changelog

Changes recorded here describe the Standard publication, not implementation
activity.

## 1.0 — 2026-09-05

- Published CCA-MEMORYOS-1.0 through MO-1208.
- Standardized the existing Runtime observation boundary, deterministic
  investigation lifecycle, Investigation Core, AI Runtime Adapter, SDK, CLI,
  Cognitive Regression, and Cognitive Investigation Explorer behavior.
- Incorporated the exact frozen CCA-RF-1.0 and CCA-MIP-1.0 requirement sets by
  reference without modifying either publication.
- Published stable `CCA-MOS-*` requirements and machine-readable evidence-group
  mappings.
- Defined conformance, compatibility, versioning, Reference Implementation,
  and certification guidance.
- Introduced no new Runtime, investigation, SDK, CLI, package, Regression, or
  Explorer semantics.
