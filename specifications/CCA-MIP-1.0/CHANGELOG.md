# CCA-MIP-1.0 Changelog

## 1.0.0-draft - 2026-08-28

- Created MIP-001, the implementation-independent Memory Investigation
  Package contract.
- Defined a single RFC 8785 canonical JSON representation and the
  `application/vnd.memoryos.mip+json` media type.
- Defined manifest, technical metadata, Observation, Trace, Replay, Evolution,
  Comparative Reconstruction, extension, verification, and integrity records.
- Defined portable typed references, deterministic ordering, SHA-256 section,
  cognition, and package commitments, atomic import/export, compatibility,
  validation, and prohibited-content rules.
- Added JSON Schema, diagrams, reference packages, invalid-vector catalog, and
  conformance requirements for independent review.
